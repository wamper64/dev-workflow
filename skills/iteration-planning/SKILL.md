# 选择本轮模块并校验依赖

## 1. 职责与范围

本技能负责完成「选择本轮模块并校验依赖」，为下一个研发步骤提供可审核产物。输入资料位于 `docs/input/`，产物统一位于 `docs/output/`。后端在 `code/guiwu_ruoyi/` 现有框架上扩展，前端必须沿用 `code/fld/` 原型的布局、样式与组件。

## 2. 输入

- `docs/output/05-模块拆分/项目模块清单.md`
- `模块依赖关系.md`
- `项目实施状态.md`
- `开发环境验收记录.md`

## 3. 工作步骤

1. 读取已确认模块清单和项目实施状态，区分已验收、待开发、受阻等状态。
2. 验证本轮候选模块的项目标识、字典、前置接口、真实对接条件。
3. 确定本轮可以验收的角色×场景目标和模块依赖，可以并行的标注冲突点。
4. 项目经理确认目标，开发人员确认环境与依赖实际可达。

## 4. 异常与审核

未满足依赖的模块应标记阻塞，不强行用模拟数据认定交付。

审核要求：开发人员判断依赖是否满足，项目经理确认本轮范围和业务验收目标。

不足以得出真实结论时提出关键问题和有依据的推荐。未经确认不得将推荐写成最终约束；未实际操作不得宣称已完成。涉及 Git 提交使用中文说明。

## 5. 输出

- `docs/output/06-模块迭代/本轮模块计划.md`
- `docs/output/06-模块迭代/前置依赖检查.md`
