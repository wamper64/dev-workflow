# 选择本轮模块并校验依赖 · 使用示例

**场景**：报价系统首次项目建设，当前已完成上一工作步骤。

**调用**：`/iteration-planning`

**参考输入**：
- docs/output/05-模块拆分/项目模块清单.md
- 模块依赖关系.md
- 项目实施状态.md
- 开发环境验收记录.md

**执行顺序**：读取模块池 → 检查阻塞关系 → 选择可交付模块 → 形成迭代计划

**期望输出**：
- docs/output/06-模块迭代/本轮模块计划.md
- docs/output/06-模块迭代/前置依赖检查.md

**验收**：开发人员判断依赖是否满足，项目经理确认本轮范围和业务验收目标。

> 这是示例，不是已实际执行或验收通过的项目事实。
