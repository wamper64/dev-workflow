# 项目级端到端业务验收的核查标准

1. [ ] 按确认PRD的角色×场景列出整个报价系统可验收矩阵，包括用户授权/项目、需求核对、历史计算单、匹配、成本、报价、多级审批驳回/重提、客户输出与归档、分析审计。
2. [ ] 检查真实用户从已有code/fld前端完成一条报价主链，追踪每个版本的参数、计算依据、审批及归档是否可重现。
3. [ ] 按不同角色验证授权边界、数据不可越权访问、重复操作不会双重生成审批或交付记录。
4. [ ] 覆盖失败/重试/驳回/取消及已完成模块回归，收集响应、截图、数据库状态、真正第三方接口记录。
5. [ ] 项目经理在真实证据基础上逐场景签收；无法使用真实环境的部分标未验收并说明阻塞。

## 关卡

所有关键角色场景已有真实执行结果，跨模块主/异常链无阻塞缺陷，项目经理审核同意；否则回到责任模块诊断和复测。

真实运行与人工确认要区分；缺数据/缺权限/未实际执行不可判为通过。
