# 全项目角色×场景验收门禁

## 必须逐项检查

1. [ ] 从已批准项目/模块PRD提取本项目真实角色×核心场景、主业务链、异常分支、跨模块边界；不默认任何报价、设备或审批功能。
2. [ ] 每条关键跨模块流程从实际业务入口触发，验证权限、状态流转、唯一数据Owner、可观察终态与关联记录。
3. [ ] 按项目适用条件验证越权拒绝、重复提交、重试、取消、回退、第三方故障或设备异常，并记录真实执行证据。
4. [ ] 对已完成模块执行真实跨模块回归；已有局部自动测试只引用实际运行结果，不把Mock作为外部真实连通成功。
5. [ ] 缺陷有责任模块、Bug记录、修复与原场景复测结果；项目经理逐场景确认实际状态和阻塞理由。

## 放行与退回

- **通过**：全部关键场景有真实证据、主/异常链及权限满足PRD，项目经理审核通过。
- **退回**：未测、受阻、失败或缺少真实权限/环境时，标记责任和解除条件，退回相应模块修复与复测；不得按固定菜单数或功能名称代替场景覆盖。
