# 全项目业务链路和权限回归

## 1. 职责

本技能负责「全项目业务链路和权限回归」，基于已确认的工作输入形成可追溯结果。未经确认的前置依赖应显式报告。保留 `code/fld/` 前端原型的布局和视觉规范，后端沿用 `code/guiwu_ruoyi/` 框架。

## 2. 输入

- `已确认项目模块清单.md`
- `所有模块验收记录`
- `最终可运行代码`
- `PRD`

## 3. 执行步骤

1. 根据已确认PRD按角色与业务场景建立端到端覆盖矩阵。
2. 测试登录→项目→需求解析→匹配→成本→报价→审批→交付归档及真实页面。
3. 检查审批驳回/重提、权限、业务统计、审计与已完成模块回归。
4. 归档测试证据及缺陷；存在阻塞项时退回负责模块。

## 4. 审核与异常

单个模块验收结果不能代替系统级回归。

审核要求：项目经理确认登录、17个菜单和完整报价主流程；缺陷返回关联模块。

如果缺少测试证据或真实环境权限，输出阻塞结论而非模拟通过；失败时回到相应步骤修复并复验。涉及代码提交必须使用中文说明。
