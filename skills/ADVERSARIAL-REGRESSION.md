# 自建/改造 Skill 对抗性回归标准

> 检查范围仅自建、改造及其元数据，Matt Pocock 原版保持不变。静态规则校验不代表运行项目通过。

| ID | 对抗输入 | 合格输出 |
|---|---|---|
| T01 | 12个不同生命周期、Owner和验收边界 | 可保留12个并评审，不强制合并 |
| T02 | 无页面的自动设备告警 | 模块清单含稳定key、主责、可验收结果 |
| T03 | 只有跨域读取的驾驶舱 | 有真实责任模块与跨域契约，不凭“无写入”丢弃 |
| T04 | 业务100GB、附件40GB、日志20GB、备份100GB | 基础合计260GB，再加未计入开销，不重复 |
| T05 | 同租户同编码建→删→重建→再删 | 不出现唯一键冲突，保留历史 |
| T06 | sys_user、复合键及动态菜单 | 保留既有表/合法键，识别真实菜单机制 |
| T07 | 模块顺序重排 | module_key不变，历史引用不失效 |
| T08 | 本地/GitHub/GitLab Tracker 切换 | 任务与真实Spec映射仍可定位 |
| T09 | 模块设计更新后审查旧任务 | 旧Spec有设计基线SHA/快照 |
| T10 | 修复后两次部署再复测 | 每轮保留构建、环境、数据与结果 |
| T11 | 模块PRD含项目PRD未细述的权限异常 | 系统验收包含且冲突先裁定 |
| T12 | 预演后修改SQL或重构镜像 | 旧发布指纹失效，阻断直到受影响关卡重验 |
| T13 | 验证生产备份可恢复 | 恢复只能打隔离副本，不覆盖生产权威 |
| T14 | 部署模板嵌入破坏性命令 | 配置批准不等于命令批准，拦截并要求单独授权 |
| T15 | 正式产物与catalog.json输出比较 | 过时文件、错误章节与导航状态失配为0 |

**执行记录**：每次跑测试要记录输入用例/Skill修订SHA/运行环境/实际模型输出/人工判定，未执行标`未执行`，不能将本规则清单冒充已通过测试。
