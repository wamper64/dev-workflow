# 复盘完整研发流程并沉淀 Skill 改进

## 1. 职责

本技能负责「复盘完整研发流程并沉淀 Skill 改进」，基于已确认的工作输入形成可追溯结果。未经确认的前置依赖应显式报告。保留 `code/fld/` 前端原型的布局和视觉规范，后端沿用 `code/guiwu_ruoyi/` 框架。

## 2. 输入

- `各阶段审核记录`
- `每轮模块计划与验收`
- `AI开发会话复盘.md`
- `上线交付记录`

## 3. 执行步骤

1. 汇总项目基线、架构评审、模块开发、集成、上线中的真实返工与时间开销。
2. 区分编码会话内部的Matt retro与项目级阶段安排、审核与协作过程。
3. 定位Skill过细、重复产物、上下文丢失、质量关卡和自动化检查缺口。
4. 整理可执行的工作流和Skill改进，提交技术总监确认后再更新标准。

## 4. 审核与异常

不得以无证据的效率估算替代可验证复盘结论。

审核要求：技术总监确认流程调整优先级；项目经理核实业务沟通成本；改进不直接覆盖已审核基线。

如果缺少测试证据或真实环境权限，输出阻塞结论而非模拟通过；失败时回到相应步骤修复并复验。涉及代码提交必须使用中文说明。
