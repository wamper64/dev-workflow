# 开发/测试环境首次上线及更新预检门禁

1. [ ] 仅选择**开发环境或测试环境**其中之一，明确操作是**首次应用上线或版本更新**，不可把 S06 基础设施初次部署当成应用上线。
2. [ ] 核对该环境资源、现有应用/数据库、网络、端口、Compose、数据卷及环境账号，不可复用另一个环境的配置。
3. [ ] 确认发布指纹：Git Commit、前后端构建/镜像 digest、迁移 SQL checksum、脱敏配置摘要与选定环境。
4. [ ] 首次应用上线检查基础组件和初始化条件；版本更新核验旧→新版本、迁移兼容、现存数据与回退点。
5. [ ] 风险涉及数据库、附件或配置时制作必要备份；如需验证恢复，只能在**隔离副本**或独立实例验证，不能污染真实环境数据。
6. [ ] 危险 SQL、删除卷、覆盖数据等必须针对目标取得**单独授权**；未经授权不得执行。
7. [ ] 在批准的隔离范围核对迁移/启动/回退路径；未通过预检或未获该环境操作授权不能进入实际部署。
8. [ ] 开发、测试环境分别留证，未经执行不写通过。
