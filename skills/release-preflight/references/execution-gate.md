# 生产部署与回滚预演门禁

## 必须逐项检查

1. [ ] 核验目标服务器或批准的等效预演环境CPU、RAM、磁盘、操作系统、网络、容器运行时、权限和实际端口占用。
2. [ ] 核对不可变应用/镜像版本、签收的迁移脚本、执行顺序、私有配置注入及真实第三方接口可用条件；不在Git中保存口令。
3. [ ] 备份业务数据库、必要附件和关键配置，并实际执行恢复演练，比较恢复后主对象及关联数据的一致性。
4. [ ] 在授权预演环境按生产顺序运行发布和增量迁移，保存命令、退出状态、健康检查和本项目PRD核心业务冒烟证据。
5. [ ] 演练应用回滚以及数据库安全回退/前向修复，确保本项目关键业务数据、引用和必要审计记录无损；不可逆DDL须单独批准或阻断。
6. [ ] 技术总监审核环境差异、数据可恢复性、步骤可重复性与应急处置权限。

## 放行与退回

- **通过**：真实备份可恢复、发布路径可复现、回滚或向前修复有可操作证据，并获得批准。
- **阻断**：目标机不可访问、未授权、恢复未验证、数据不可恢复或预演失败时只输出计划/阻塞单，不宣称已准备上线。
