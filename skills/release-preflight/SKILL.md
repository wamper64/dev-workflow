# 生产环境核验、部署预演与回滚准备

## 1. 职责

本技能负责「生产环境核验、部署预演与回滚准备」，基于已确认的工作输入形成可追溯结果。未经确认的前置依赖应显式报告。保留 `code/fld/` 前端原型的布局和视觉规范，后端沿用 `code/guiwu_ruoyi/` 框架。

## 2. 输入

- `docs/input/环境资料/`
- `上线评审结论.md`
- `code/`
- `database/migrations/`

## 3. 执行步骤

1. 核查目标生产服务器实际资源、访问权限、网络和必要中间件状态。
2. 明确发布步骤与数据库增量迁移顺序，准备备份、回滚和配置隔离方案。
3. 在受控环境预演升级、业务冒烟、故障回退并记录验证结果。
4. 预演失败或无法恢复则停止发布，直到重新验收。

## 4. 审核与异常

不将开发环境的验证当作目标生产环境已经就绪。

审核要求：技术总监确认目标环境与预演结果；有破坏性SQL或无法回滚不得贸然上线。

如果缺少测试证据或真实环境权限，输出阻塞结论而非模拟通过；失败时回到相应步骤修复并复验。涉及代码提交必须使用中文说明。
