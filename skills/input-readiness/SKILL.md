# 输入就绪确认

## 1. 职责与范围

本技能负责完成「输入就绪确认」，为下一个研发步骤提供可审核产物。输入资料位于 `docs/input/`，产物统一位于 `docs/output/`。后端在 `code/guiwu_ruoyi/` 现有框架上扩展，前端必须沿用 `code/fld/` 原型的布局、样式与组件。

## 2. 输入

- `docs/input/需求资料/（已确认PRD）`
- `docs/input/工程资料/（如有）`
- `docs/input/环境资料/（如有）`
- `docs/input/对接资料/（如有）`
- `code/fld/（已存在原型）`
- `code/guiwu_ruoyi/（仅确认框架在位）`

## 3. 工作步骤

1. 核验实际PRD文件及其可用于设计的确定内容，而不是只检查文件夹名称。
2. 资料目录中工程、环境和对接信息可为空，但记录会影响下一步的真实缺口。
3. 检查code/fld原型目录存在、code/guiwu_ruoyi框架目录存在；不做框架源码质量评审。
4. 只对会阻断后续项目基线及架构的矛盾提问题并告知项目经理。

## 4. 异常与审核

不把缺失的可选资料等同于项目不能开始。

审核要求：项目经理确认PRD可作为实施依据、可选材料可追溯、前端原型和后端框架已放置；不对若依内部代码进行技术审核。

不足以得出真实结论时提出关键问题和有依据的推荐。未经确认不得将推荐写成最终约束；未实际操作不得宣称已完成。涉及 Git 提交使用中文说明。

## 5. 输出

- `docs/output/01-项目基线/输入核对.md`
- `docs/output/01-项目基线/待确认事项.md`
