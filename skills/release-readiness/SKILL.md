# 非功能指标及上线评审

## 1. 职责

本技能负责「非功能指标及上线评审」，基于已确认的工作输入形成可追溯结果。未经确认的前置依赖应显式报告。保留 `code/fld/` 前端原型的布局和视觉规范，后端沿用 `code/guiwu_ruoyi/` 框架。

## 2. 输入

- `docs/output/01-项目基线/项目基线.md`
- `架构设计.md`
- `全流程验收报告.md`
- `系统运行记录`

## 3. 执行步骤

1. 以工程基线的负载、资源、安全、恢复目标为上线门槛，不重复制定任意指标。
2. 核查有据可查的非功能结果，区分未测试、测试失败和已通过。
3. 明确上线风险、未关闭问题及可接受的例外条件。
4. 技术总监核实证据并决定批准预演或退回整改。

## 4. 审核与异常

不得将目标值误写成实测结果。

审核要求：技术总监评审性能/可用性/备份/安全与发布风险；没有实测不能填通过。

如果缺少测试证据或真实环境权限，输出阻塞结论而非模拟通过；失败时回到相应步骤修复并复验。涉及代码提交必须使用中文说明。
