# 上线就绪与非功能审核门禁

## 必须逐项检查

1. [ ] 从已批准项目基线提取本项目真实负载：用户在线量、HTTP请求峰值、设备/测点采集、后台任务和数据增长（仅适用项）；目标有数值、单位、口径。
2. [ ] 在批准的数据集、请求/任务分布及持续时长下，实测P95/错误率、CPU、RSS、磁盘、DB连接、消息积压等适用指标；不能默认72小时或把在线人数当HTTP并发。
3. [ ] 核对项目适用的身份鉴权、数据权限、敏感信息脱敏、审计、第三方调用授权及运行监控。
4. [ ] 对实际业务对象核对留存/归档/删除起算要求、真实备份恢复和RPO/RTO。备份任务运行成功不能证明可恢复。
5. [ ] 按“批准目标—负载条件—实测结果—来源证据—风险/责任人—裁定”记录各项，技术总监逐项放行或退回。

## 放行与退回

- **通过**：关键指标具有相同测量口径的达标证据，安全/数据风险及恢复约束经审核。
- **退回或有条件处理**：缺少实测、环境不符或不可恢复时不得写“通过”；风险接受须有具体条件、批准人和仍待验证项。
