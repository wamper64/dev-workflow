# 本轮收口的硬性门禁

- [ ] 已选择模块均有正式Spec、Tickets与可定位Git提交
- [ ] implement-spec内置TDD、必要联通验证与code-review确实运行、有结果或真实阻塞
- [ ] 不存在额外重复的独立review/同一批自动化测试确认项
- [ ] 人工测试用例与结果.md由人填写：关键用例有执行人、环境、实际结果、证据
- [ ] 若有Bug，采用官方diagnosing-bugs六阶段后人工对原用例复测并回填同一文件
- [ ] 实际第三方未联通不得列为真实验收通过
- [ ] 项目经理/开发人员在职责范围内批准
- [ ] 更新项目实施状态，不修改旧轮已验收事实
- [ ] 全部模块都已签收，才可进入总系统验收
