# 收口本轮并进入下一轮（可选 retro）

## 1. 职责

本技能负责「收口本轮并进入下一轮（可选 retro）」，基于已确认的工作输入形成可追溯结果。未经确认的前置依赖应显式报告。保留 `code/fld/` 前端原型的布局和视觉规范，后端沿用 `code/guiwu_ruoyi/` 框架。

## 2. 输入

- `本轮验收记录.md`
- `缺陷任务`
- `项目模块清单.md`
- `项目实施状态.md`

## 3. 执行步骤

1. 对照本轮Spec、Tickets、SQL、评审与验收资料确认交付证据完整。
2. 按已验收/开发中/受阻/未开始维护模块状态，并核查剩余依赖。
3. 把失败项转可复现任务，出现重复Agent误用时可调用Matt retro。
4. 全部模块完成才进入整系统验收，否则进入下一轮模块选择。

## 4. 审核与异常

单纯代码合并不等于模块验收通过。

审核要求：项目经理确认本轮场景完成；剩余模块返回S15，有重大AI开发问题时调用retro改进工程环境。

如果缺少测试证据或真实环境权限，输出阻塞结论而非模拟通过；失败时回到相应步骤修复并复验。涉及代码提交必须使用中文说明。

- `docs/output/06-模块迭代/本轮总结.md`
- `按需：研发环境改进项`
