# 项目模块清单

**一张表，列固定**：`序号 | module_key | 阶段 | 阶段模块/交付能力 | 第三方对接`（末列仅当项目有外部系统时保留，否则删去）。
**阶段**＝业务模块（可分批交付单元，**超过10个须说明理由并取得粒度评审**）；**阶段模块/交付能力**＝前端页面名称、页内功能及无页面后台/事件/定时/Agent/跨域聚合能力（均须给可验收结果）（页内跨阶段功能写 `页面名·功能名`、整页扣除写 `页面名（不包含 功能名）`）；**第三方对接**＝该阶段要对接的外部系统及用途；**module_key**＝不随排序变化的稳定标识；**序号**＝交付/使用顺序，身份与登录类排在最前。

**命名与核对（做完表即完成覆盖核验）**

- 页面名称从当前工程实际的单/多文件路由、动态菜单、权限表或i18n权威资源读取；`src/router/index.js` 仅是示例，不是固定路径；同名不同页加限定（如"设备详情（概况）"）。
- **最小单元是功能，不是页面**（SKILL §3.2.1）：页内某功能属于另一阶段时，在该阶段行点名 `页面·功能`（如"人员管理·分配电站"归电站阶段）；概览/统计页按数据来源分摊，不整页推给末尾统计阶段。
- **整页＝全部功能**：写整页名即含该页全部功能；页内某功能归他阶段时，本阶段写 `页面名（不包含 功能名）`（如"人员管理（不包含 分配电站）"），该功能在其所属阶段写 `页面名·功能名`——各阶段并集＝全部功能，范围无歧义。
- **第三方对接归位**：架构外部对象清单里每个系统都在某阶段列出一次，首次对接与后续复用区分标注；无遗漏、无默认后置。
- 前端每个页面/功能恰好出现在其主责阶段：缺失＝漏项、多次出现＝重复、超出＝无依据，当场在表内补/删/改。
- 本表**不写**职责、Owner、依赖；这些见《模块依赖关系》与上游 PRD/数据库总体设计。
