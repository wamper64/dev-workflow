# 完成模块集成联调与验收

## 1. 职责

本技能负责「完成模块集成联调与验收」，基于已确认的工作输入形成可追溯结果。未经确认的前置依赖应显式报告。保留 `code/fld/` 前端原型的布局和视觉规范，后端沿用 `code/guiwu_ruoyi/` 框架。

## 2. 输入

- `本轮各模块代码与SQL`
- `对应Spec`
- `本轮模块计划.md`
- `角色场景PRD`

## 3. 执行步骤

1. 将通过代码审查的模块合入已有系统，核对数据库迁移和登录/API接入。
2. 运行当前模块与前置模块的主要链路、异常路径、权限和版本一致性。
3. 根据角色×业务场景验收并回归已经完成的模块，保留真实联调证据。
4. 未通过时定位具体Ticket修复，重新执行相应测试。

## 4. 审核与异常

不可用模拟响应冒充真实第三方联调；无法验证时标注受限。

审核要求：开发人员完成全链路联调；项目经理按角色×场景验收，不通过退回S19。

如果缺少测试证据或真实环境权限，输出阻塞结论而非模拟通过；失败时回到相应步骤修复并复验。涉及代码提交必须使用中文说明。
