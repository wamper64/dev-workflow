# 初次部署审核门禁

- [ ] 先读真实`code/deploy/single-node-docker/初次部署配置.md`第1～8节及8.1/8.2/8.3，核实实际Docker部署包支持能力。
- [ ] 从docs/input及S03/S04/S05预填；资料有事实就不要再要求用户重复填写。
- [ ] 环境数由项目决定，每环境一份`初次部署配置-<环境名称>.md`，不得覆盖原模板或其它环境配置。
- [ ] IP、端口占用、SSH权限、未知版本与密码不能猜；非敏感未知项给推荐及待确认，私密值走本地私有配置。
- [ ] 严格校验环境隔离：目录、Compose、容器/网络/volume、宿主机端口、数据库、Redis和RabbitMQ命名各自独立。
- [ ] 数据库/技术组件选择与批准的S04/S05或部署包不一致时，必须先提出冲突、获得技术确认，不得暗换组件。
- [ ] 每个环境先经用户审核确认**完整配置及部署授权**；未获当前环境授权时不SSH、不上传、不运行Compose。
- [ ] 部署时必须遵循该份配置8.1执行提示词及8.2步骤、先核对已有项目和端口；只部署勾选为是且实际支持的基础服务。
- [ ] 首次不启动ruoyi、nginx，不检查jar/dist存在，仅保留package路径；不对既有数据卷做删除/重建。
- [ ] 8.3各环境独立真实验证本机健康和异机端口，无法测标待人工验证；本地生成独立部署结果README。
