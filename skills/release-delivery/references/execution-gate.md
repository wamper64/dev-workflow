# 开发/测试应用首次上线与更新门禁

1. [ ] 目标环境只能是开发或测试；发布类型只能是首次应用上线或版本更新。
2. [ ] 检查该环境专属配置、原版本、资源、网络、端口、卷、数据库及发布指纹，避免误覆盖另一环境。
3. [ ] 已由 release-preflight 完成该环境预检、必要备份与回退验证；实际部署另有明确授权。
4. [ ] 首次应用上线核查基础服务、应用配置和启动入口；更新核查旧→新版、必要数据库迁移、已有数据保护和回归。
5. [ ] 记录执行人、真实命令、时间、退出码、构建/镜像/迁移摘要和健康检查。
6. [ ] 从该环境入口执行当前项目 PRD 适用的业务冒烟，不把 Mock 或另一环境结果冒充真实验证。
7. [ ] 故障按已批准路径回退或修复；涉及破坏性动作先取得**单独授权**。
8. [ ] 环境负责人检查真实证据并签收该环境版本，失败/未测/受阻不得写成发布成功。
