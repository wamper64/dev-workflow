# 真实生产发布与项目交付的核查标准

1. [ ] 核对已批准的版本Commit/镜像tag、DB迁移脚本摘要、备份完整性和操作窗口。
2. [ ] 按照通过预演的顺序，在有权限的目标环境真实部署应用与DB迁移；逐项记录命令、版本、实际退出状态，不冒险覆盖未知生产库。
3. [ ] 从客户访问入口验证登录、报价项目、需求核对、成本与审批、导出归档的生产冒烟链路，记录业务结果与第三方真实连通状态。
4. [ ] 部署后观察真实资源、日志、队列/任务、数据库连接和关键业务错误，出现阻塞异常按经批准的回滚/前向修复路径执行。
5. [ ] 整理可运行版本、备份恢复路径、日志排障、运维联系人、用户验收和交付文档，分别由开发人员、技术总监、项目经理作职责内确认。

## 关卡

真实目标服务器部署有成功日志且核心业务可用并完成批准的交接；不能以预演结果替代生产上线结果。

真实运行与人工确认要区分；缺数据/缺权限/未实际执行不可判为通过。
