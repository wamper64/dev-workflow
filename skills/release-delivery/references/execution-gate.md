# 正式上线及项目交付门禁

## 必须逐项检查

1. [ ] 核对技术总监批准的不可变Commit/镜像摘要、数据库迁移版本、操作窗口、回滚点与真实授权。
2. [ ] 按通过的预演在目标环境执行发布及迁移，保存实际命令、返回码、部署版本、必要备份、健康检查和脱敏日志。
3. [ ] 从客户真实访问入口按S16确认的代表性角色×核心场景执行生产冒烟；按项目真实适用项验证权限、设备/第三方接入、业务状态、输出文件等，不套固定报价流程。
4. [ ] 持续观察CPU/RSS/磁盘、DB连接、任务/消息队列、应用异常及外部接口；出现重大缺陷按已批准方案停止发布、回滚或前向修复。
5. [ ] 输出上线记录、交付清单、运行/备份/日志说明、实际版本与运维联系人；开发人员、技术总监和项目经理分别确认职责内事项。

## 放行与退回

- **通过**：生产已实际执行成功，核心业务真实可用，监测无阻塞问题且交接及签收完成。
- **退回**：只有测试或预演记录、缺少生产权限、业务冒烟未测或核心风险未解决时不得宣称成功上线。
