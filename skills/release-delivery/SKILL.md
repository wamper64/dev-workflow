# 生产部署、验收与交付

## 1. 职责

本技能负责「生产部署、验收与交付」，基于已确认的工作输入形成可追溯结果。未经确认的前置依赖应显式报告。保留 `code/fld/` 前端原型的布局和视觉规范，后端沿用 `code/guiwu_ruoyi/` 框架。

## 2. 输入

- `部署预演.md`
- `备份回滚方案.md`
- `可发布代码`
- `上线评审结论.md`

## 3. 执行步骤

1. 核对上线批准、已签署的部署预演结果与备份恢复条件。
2. 按冻结版本与顺序执行应用部署、数据库迁移及必要服务启动。
3. 实际运行核心报价与审批路径的冒烟检查，查看日志/告警。
4. 记录可追溯版本、恢复操作、问题、交接结果和交付清单。

## 4. 审核与异常

没有环境权限时应交付待执行计划，不能假称生产发布成功。

审核要求：开发人员实际操作并留证；项目经理确认业务可用，技术总监确认正式上线结果。

如果缺少测试证据或真实环境权限，输出阻塞结论而非模拟通过；失败时回到相应步骤修复并复验。涉及代码提交必须使用中文说明。
