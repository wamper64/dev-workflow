# 项目基线 · 使用示例

**场景**：报价系统首次项目建设，当前已完成上一工作步骤。

**调用**：`/project-baseline`

**参考输入**：
- docs/input/需求资料/PRD
- docs/input/工程资料/已定方案与技术栈
- docs/input/环境资料/
- docs/input/对接资料/
- docs/output/01-项目基线/输入核对.md

**执行顺序**：读取已确认PRD → 提取项目共性约束 → 核对工程资料 → 评审基线

**期望输出**：
- docs/output/01-项目基线/项目基线.md

**验收**：项目经理确认业务交付边界；开发人员确认已选技术栈、原型复用和部署约束有据可依。

> 这是示例，不是已实际执行或验收通过的项目事实。
