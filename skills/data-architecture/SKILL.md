# 数据库设计（总体）

## 1. 职责与范围

本技能负责完成「数据库设计（总体）」，为下一个研发步骤提供可审核产物。输入资料位于 `docs/input/`，产物统一位于 `docs/output/`。后端在 `code/guiwu_ruoyi/` 现有框架上扩展，前端必须沿用 `code/fld/` 原型的布局、样式与组件。

## 2. 输入

- `docs/output/01-项目基线/项目基线.md`
- `docs/output/02-整体架构/整体架构设计.md`
- `docs/input/环境资料/`

## 3. 工作步骤

1. 依据整体架构、PRD和项目基线确定数据权威来源及各业务数据域。
2. 划分报价项目、需求参数、历史计算单、模板、成本、报价审批及归档等数据责任。
3. 估算实际规模，讨论单库、独立库、分库分表适用条件及扩容代价。
4. 审查跨域一致性、审计、保留期与备份策略，提交技术总监审核。

## 4. 异常与审核

本步骤不生成具体表字段、索引与DDL。

审核要求：技术总监确认数据域划分、单库/分库分表及容量策略；明确不涉及具体表字段。

不足以得出真实结论时提出关键问题和有依据的推荐。未经确认不得将推荐写成最终约束；未实际操作不得宣称已完成。涉及 Git 提交使用中文说明。

## 5. 输出

- `docs/output/03-数据库总体/数据库总体设计.md`
- `docs/output/03-数据库总体/数据库设计审核.md`
