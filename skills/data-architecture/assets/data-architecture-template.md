```mermaid

  %% 节点＝数据域；边＝域间关联（键，方向）
```

**依据与作用：** 一个域＝**一族同生命周期的核心对象**，以「**权威写方 / 保留边界 / 一致性边界**」判定；**关系表（tr_）不单独成域**，归入它服务的对象族所在域；框架对象族与其业务扩展表服务同一对象族时同域（域内按表标注写方）。域数保持精简，能合则合；只有对象族、保留或写方边界确实不同才独立成域。作用是归口、边界、落位。
