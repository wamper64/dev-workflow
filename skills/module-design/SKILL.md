# 完成本轮模块详细设计

## 1. 职责与范围

本技能负责完成「完成本轮模块详细设计」，为下一个研发步骤提供可审核产物。输入资料位于 `docs/input/`，产物统一位于 `docs/output/`。后端在 `code/guiwu_ruoyi/` 现有框架上扩展，前端必须沿用 `code/fld/` 原型的布局、样式与组件。

## 2. 输入

- `本轮模块计划.md`
- `docs/input/需求资料/PRD`
- `已有代码/页面`
- `整体架构设计.md`
- `数据库总体设计.md`

## 3. 工作步骤

1. 以本轮模块PRD、现有代码、项目架构与数据库总体设计为输入。
2. 设计模块业务状态、失败路径、权限、具体数据表字段索引、API契约及版本规则。
3. 确认沿用code/fld原型中的组件和样式、若依可复用能力，不新造平行实现。
4. 通过模块设计审查；涉及跨模块/系统级变更时先交技术总监。

## 4. 异常与审核

仅为当前迭代模块生成详细设计，不提前展开其他模块。

审核要求：开发人员审核业务逻辑和数据关系；更改全局架构、数据库域时需技术总监确认。

不足以得出真实结论时提出关键问题和有依据的推荐。未经确认不得将推荐写成最终约束；未实际操作不得宣称已完成。涉及 Git 提交使用中文说明。

## 5. 输出

- `docs/output/06-模块迭代/<模块>/模块详细设计.md`
- `database/migrations/<模块>*.sql（设计后形成）`
- `按需：docs/adr/*.md`
