# 全项目业务验收 · 报价系统使用示例

> 示例非真实验收结果。不得假定报价项目固定有17个菜单或所有流程已实现。

**输入**：已确认PRD/原型、全项目模块清单与依赖、所有已签收模块任务、当前真实环境及可运行代码、系统级安全/性能约束。

## 执行流程

1. 按**角色×核心场景**反向形成模块覆盖矩阵，识别跨模块主链、异常/驳回/重试和数据权限拒绝。
2. 对已实现的真实页面与接口执行系统级端到端链路验证，记录环境、账号角色、输入、步骤、输出与证据；重点核对需求参数版本→方案匹配→报价版本→审批→归档之间数据与状态引用。
3. 检查不同角色/项目数据隔离、登录和操作权限；不可达的外部系统或设备明确标受阻，模拟通过不能算真实通过。
4. 缺陷按主责模块回到原任务修复及同场景复测，形成真实缺陷闭环。
5. 项目经理核对PRD已确认的全部业务能力、菜单/页面覆盖及真实通过证据，未测/受阻不得签收。

**输出**：`docs/output/07-系统验收/全流程验收报告.md` 及 `缺陷闭环记录.md`（以Skill产物约定和项目真实执行为准）。
