# 系统业务验收 · 报价系统使用示例

> 示例非真实验收结果。实际验收范围只来自客户已确认的项目PRD和模块PRD。

**输入**：PRD/原型、模块清单和已完成的实际签收、真实环境、角色账号、已有自动/人工测试和联调证据。

## 执行流程

1. 从角色×核心场景构造覆盖表，**直接填写在系统验收报告第2章**；需要审批/归档等能力时，以真实PRD为依据。
2. 在真实页面及接口执行跨模块业务主链与异常/越权场景，核对实际状态、版本/引用、响应及可复现证据。
3. 失败和缺失第三方条件均在**同一份报告的缺陷/受阻章节**记录责任与复测，不另生成文件。
4. 项目经理在报告末章核对全业务范围与通过率，阻断项未解决不签收通过。

**唯一正式输出**：`docs/output/07-系统验收/系统验收报告.md`，其中包括角色场景覆盖、系统回归、缺陷闭环和签收结论。
