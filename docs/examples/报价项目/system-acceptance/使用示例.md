# 系统业务验收使用示例（报价业务演示）

**调用**：`/system-acceptance`

**输入**：已确认项目PRD与模块PRD、审核通过的模块清单和实际签收状态、可运行前后端及第三方环境。

**执行流程**：角色×核心场景覆盖表 → 跨模块主/异常链实测 → 角色/数据权限与幂等核验 → 缺陷关联模块修复和复测 → 项目经理按场景签收。

**示例业务链**（仅当真实项目PRD确有此流程）：项目创建→资料核对与参数确认→报价编制→提交审批→驳回重提或批准→交付输出；每一步核实权威状态、权限和业务结果。没有此流程的项目不得照抄。

**输出**：`docs/output/07-系统验收/业务场景覆盖矩阵.md`、`docs/output/07-系统验收/系统验收报告.md`，缺陷另记`缺陷闭环记录.md`。

**放行**：每个关键场景有真实执行证据；受阻、未测及失败不能标已通过。此文件只是说明，不是实际完成的项目验收报告。
