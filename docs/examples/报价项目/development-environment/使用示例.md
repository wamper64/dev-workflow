# 初次部署配置演示（仅示例，不是实际部署）

1. 读取项目`code/deploy/single-node-docker/初次部署配置.md`原始8节与部署包。
2. 假设项目**明确有开发与测试两个环境**，结合PRD、工程/环境资料和批准S03/S04/S05，自动生成`初次部署配置-开发环境.md`与`初次部署配置-测试环境.md`；服务器IP/已用端口/访问权限若未知标待确认并推荐。
3. 两份配置分别确认，绝不凭开发环境授权就执行测试环境。
4. 获批后严格按照本环境配置8.1提示词与8.2检查部署，只部署启用的数据库、中间件；不启动ruoyi/nginx，预留package jar/dist位置。
5. 按8.3逐环境真实验证本机及异机连通性，分别写`部署结果README-开发环境.md`和`部署结果README-测试环境.md`。

本示例不代表用户的真实项目一定采用PostgreSQL或两套环境；真实组件以已确认架构和部署包支持为准。
