# 报价系统开发环境：先填写表格再执行（演示）

> 这是演示操作流程，不代表已经读取用户真实电脑配置，也不代表服务已经部署。

## 1. 用户在研发导航右侧填写

| 表格项目 | 模拟填写示例（须用户自己替换成真实信息） |
|---|---|
| 开发主机 | Windows 11 + Docker/WSL2（仅示例） |
| CPU/内存/磁盘 | 8核/16GiB/实际磁盘剩余量待核实 |
| 已有环境 | MySQL已有，版本/端口待核实；Redis暂不确认 |
| 可用目录 | 用户填写本机真实环境目录，**Skill不得硬编码某人路径** |
| 端口与网络 | 当前已占用端口、Nginx/MySQL实际端口，外网/代理限制 |
| 操作授权 | 本机是否允许Docker及新增容器，哪些已有数据库禁止变更 |

完成后在右侧点击“下载填写表（Markdown）”，把文件放到 `docs/input/环境资料/开发环境信息.md`。

## 2. Skill读表后生成部署顺序

1. 检查真实现有MySQL是否符合项目基线/数据库总体设计：可复用则不新增。
2. 根据已批准整体架构核对必需的Redis/消息/知识服务；**没有真正需要就不部署**。
3. 申请允许安装的端口和持久数据目录，确认没有覆盖现存应用。
4. 必要时生成Docker Compose/启动配置，逐项执行并记录命令和退出码。
5. 实际启动既有 `code/guiwu_ruoyi/` 和 `code/fld/` 并通过数据库与真实API/页面联通测试。

每步在部署记录中填写：**计划命令、实际结果、失败原因、下一步处理**。未经真实执行的状态只能是“待执行/受阻”，不能填已通过。
