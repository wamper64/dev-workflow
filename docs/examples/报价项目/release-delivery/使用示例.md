# 生产部署、验收与交付 · 使用示例

**场景**：报价系统首次项目建设，当前已完成上一工作步骤。

**调用**：`/release-delivery`

**参考输入**：
- 部署预演.md
- 备份回滚方案.md
- 可发布代码
- 上线评审结论.md

**执行顺序**：备份 → 部署/迁移 → 业务冒烟 → 交接文档

**期望输出**：
- docs/output/08-上线交付/上线记录.md
- docs/output/08-上线交付/交付清单.md

**验收**：开发人员实际操作并留证；项目经理确认业务可用，技术总监确认正式上线结果。

> 这是示例，不是已实际执行或验收通过的项目事实。
