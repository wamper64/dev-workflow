# 上线部署·首次上线与版本更新 · 报价系统示例

**输入**：目标开发/测试/正式环境专属配置，本次是否首次应用上线、批准构建与 SQL、部署预演和备份回滚方案；正式环境另需两项系统验收放行。

**实际执行**：核对版本 → 按授权部署或升级迁移 → 环境业务冒烟 → 观察 → 必要时批准回滚 → 记录交接。首次应用上线不能误删存量库；更新不能覆盖其他环境的卷、端口和配置。

**正式输出**：`docs/output/08-上线交付/上线记录.md`、`交付清单.md`。两份文件应明确环境、首次/更新类型、旧版→新版、执行人、授权和真实结果。

> 开发/测试验收成功不等于正式上线成功；这是情景示例，不代表已发布。
