# 报价系统：开发/测试环境应用上线示例

**四种选项**：开发首次上线、开发更新、测试首次上线、测试更新。每次只选其中一个环境和一种操作。

**输入**：该环境已确认配置、构建/镜像与必要 SQL、当前版本/数据状态、环境负责人批准范围。

**执行**：先用 `release-preflight` 检查隔离、备份/回退并得到审核结论，再由 `release-delivery` 执行实际应用部署，验证健康和当前 PRD 的业务冒烟。

**输出**：同一部署步骤生成 `部署预演.md`、`备份回滚方案.md`，实际成功发布时生成 `上线记录.md` 与 `交付清单.md`。

> 测试环境发布不能使用开发环境数据或日志冒充；本例不是实际发布记录。
