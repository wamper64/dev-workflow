# 工程基线示例（内容及数值仅说明结构，非报价项目真实裁定）

## 1. 第一性原则与取舍

| 原则 | 取舍与禁止边界 |
|---|---|
| 人工确认优先 | 系统自动解析得出的候选参数未经用户确认，不得成为正式计算依据 |
| 版本可追溯 | 成本与报价的最终版本必须能追溯到用于计算的参数和模板版本 |

## 2. 技术与部署边界

| 项目 | 约束 |
|---|---|
| 前端 | 已有原型作为开发基础，延用风格与组件；不重新创建平行页面 |
| 后端 | 现有若依框架扩展，保留可复用的权限结构 |

## 3. 规模与资源

| 需要确定的目标 | 必须明确的口径 |
|---|---|
| 在线人数 | 与实际请求并发分开 |
| 批量解析 | 文件量、任务并发、执行和排队时间分别定义 |
| 持续运行 | 内存、连接数、日志占用的测量上限与超限行为 |

> 示例不包含用户未确认的服务器规格、并发、数据保留或SLA。这些应在会话给出备选并确认后才写进正式工程基线。
