# 非功能指标及上线评审 · 使用示例

**场景**：报价系统首次项目建设，当前已完成上一工作步骤。

**调用**：`/release-readiness`

**参考输入**：
- docs/output/01-项目基线/项目基线.md
- 架构设计.md
- 全流程验收报告.md
- 系统运行记录

**执行顺序**：核对非功能与安全 → 风险评估 → 上线门禁 → 技术总监审核

**期望输出**：
- docs/output/07-系统验收/性能安全检查.md
- docs/output/07-系统验收/上线评审结论.md

**验收**：技术总监评审性能/可用性/备份/安全与发布风险；没有实测不能填通过。

> 这是示例，不是已实际执行或验收通过的项目事实。
