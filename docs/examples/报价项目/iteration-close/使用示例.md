# 收口本轮并进入下一轮（可选 retro） · 使用示例

**场景**：报价系统首次项目建设，当前已完成上一工作步骤。

**调用**：`/iteration-close`

**参考输入**：
- 本轮验收记录.md
- 缺陷任务
- 项目模块清单.md
- 项目实施状态.md

**执行顺序**：核对验收证据 → 更新模块状态 → 检查剩余依赖 → 进入下一轮

**期望输出**：
- docs/output/项目总控/项目实施状态.md（更新）
- docs/output/06-模块迭代/本轮总结.md
- 按需：研发环境改进项

**验收**：项目经理确认本轮场景完成；剩余模块返回S15，有重大AI开发问题时调用retro改进工程环境。

> 这是示例，不是已实际执行或验收通过的项目事实。
