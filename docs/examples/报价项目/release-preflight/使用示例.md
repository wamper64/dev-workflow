# 上线部署·预检与回滚预演 · 报价系统示例

**先选择两个维度**：环境=开发/测试/正式；类型=首次应用上线/已有版本更新。以下只是示例，不代表真实部署。

- 开发/测试首次应用上线：先确认 S06 的数据库与中间件已部署，再核对应用镜像、端口、隔离数据卷、首建依赖及健康。
- 开发/测试已有版本更新：查当前运行版本、SQL变更、测试数据、升级兼容及独立回滚点。
- 正式环境首次上线或更新：必须先有 S16 系统业务验收报告、S17 系统质量验收与上线评审通过，且预演与危险操作分别得到批准。

**正式输出**：`docs/output/08-上线交付/部署预演.md` 与 `备份回滚方案.md`。生产数据库恢复只能在隔离副本演练；不能把演练成功说成已上线。
