# 上线预检与预演使用示例（报价业务演示）

**调用**：`/release-preflight`

**输入**：目标环境实际信息、上线评审结论、已批准不可变版本、真实部署脚本、数据库迁移清单及备份恢复条件。

**执行流程**：核查目标机权限与资源→核对应用包和迁移→真实备份并尝试恢复→授权的独立环境预演→回滚或前向修复演练→技术总监审批。

**项目内落点**：优先沿用真实`code/deploy/`及已经确认的部署体系，不规定必须存在`deploy/docker-compose.yml`或`deploy/nginx/`；按实际部署工具决定运行命令。

**产物**：`docs/output/08-上线交付/部署预演.md`、`docs/output/08-上线交付/备份回滚方案.md`，包括运行命令、版本、退出状态与可恢复证据。

**放行**：破坏性SQL、未验证恢复、无操作权限时标受阻，不能仅凭部署命令草稿宣布可以正式上线。本示例不表示客户生产机已经执行过预演。
