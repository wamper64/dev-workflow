## 3. 外部工具与资料边界

本GitHub仓库未附正式`docs/input/`或`code/`客户工程，因此网站的报价系统示例均为**基于已讨论场景的示范产物**。没有真实环境执行记录、真实接口或人员签收，不能宣布客户项目已按Skill运行完成。


## S03 项目基线约束边界（2026-10-12更新）

S03不是需求解析或架构设计：输入PRD/原型仅作为识别约束的依据；从需求提取出的规模、时效、精度、数据量、期限、负载等事实，应记录具体值、单位、周期、适用范围和证据。工程禁止事项、现有资产复用和责任边界用明确的是否违规判据表达，不以PRD「本期不做」功能充当工程禁止。

顺序：自动读取并预填已知事实 → 识别按需专项和项目独有约束 → 只展示资料缺失/冲突/需负责人裁定的内容 → AI推导候选RPS、并发、容量并由技术负责人裁定 → 检查资源/数据/性能/恢复一致性 → 输出正式项目基线。基线只设定整机环境、峰值指标及工程边界；整体架构确定逐服务资源与组件部署。此过程在**既有S03内部完成**，不新增阶段或独立Skill。
