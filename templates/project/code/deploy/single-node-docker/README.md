# 单机 Docker 首次部署配置（项目初始化参考）

1. 本目录的《初次部署配置.md》来自用户提供的完整八节配置模板，**不是**可独立执行的Docker部署包。
2. 初始化真实项目时，只在目标 `code/deploy/single-node-docker/初次部署配置.md` 不存在时复制；若已有配置，保留项目原件。
3. 再读取项目真实的docker-compose、SSH脚本、初始化SQL，以及docs/input和已经批准的项目基线/总体架构/数据库总体设计。
4. 根据实际环境逐份生成 `初次部署配置-<环境名称>.md`，自动预填可证实内容；缺失项给推荐并等待用户确认。
5. 每套配置经用户确认与部署授权后，才使用**该份配置第8.1节原始提示词**及8.2步骤执行；首次只部署基础组件、数据库、中间件，不启动ruoyi/nginx。
6. 敏感环境变量只留本地私有文件，不能提交Git，使用本目录的 .gitignore 保护；真实密码不得写入配置Markdown。
